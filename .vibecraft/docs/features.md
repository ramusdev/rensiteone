# Ren VPN

## Цель проекта
Сайт-лендинг для VPN-сервиса Ren VPN, ориентированный на обычных пользователей, которые хотят безопасный интернет и защиту приватности.

## Основные возможности

### Обзор возможностей
- **Цель:** Пользователь узнаёт о ключевых преимуществах VPN-сервиса
- **Описание:** Главная страница с hero-секцией и блоками, описывающими основные возможности: шифрование трафика, отсутствие логов, высокая скорость, защита приватности, простота использования
- **Критерии приёмки:**
  - Hero-секция с заголовком, подзаголовком и двумя CTA-кнопками («Скачать с Google Play» и «Скачать .apk») отображается при загрузке страницы
  - Блоки с ключевыми возможностями (3–5 шт.) отображаются с иконками и описаниями
  - Все элементы выполнены в стиле glassmorphism

### Социальное доказательство и доверие
- **Цель:** Пользователь убеждается в надёжности сервиса и доверяет ему
- **Описание:** Секция с рейтингом, количеством пользователей и загрузок, отзывами клиентов (3–4 карточки) и логотипами изданий/наград
- **Критерии приёмки:**
  - Отображается рейтинг пользователей (4.8/5)
  - Отображается количество пользователей (1M+) и загрузок
  - Отображаются 3–4 карточки с отзывами клиентов
  - Присутствуют логотипы изданий или наград
  - Все элементы выполнены в стиле glassmorphism

### Тарифы и подписка
- **Цель:** Пользователь может выбрать подходящий тарифный план
- **Описание:** Секция с карточками тарифов: промо-тариф 3 дня за 1 руб и 1 месяц за 199 руб, где указана цена и основные преимущества каждого плана. Рядом с тарифами отображается гарантия возврата средств (30 дней без вопросов)
- **Критерии приёмки:**
  - Отображаются 2 тарифных плана в виде карточек
  - У каждого плана указана цена и список включённых возможностей
  - Отображается информация о 30-дневной гарантии возврата средств

### Скачать приложение
- **Цель:** Пользователь может скачать приложение на Android
- **Описание:** Секция с двумя вариантами скачивания для Android: Google Play и .apk файл
- **Критерии приёмки:**
  - Отображаются две кнопки/карточки: «Скачать с Google Play» и «Скачать .apk»
  - Каждая кнопка содержит иконку и название
  - Секция адаптирована под мобильные устройства

### Поддержка пользователей
- **Цель:** Пользователь знает, куда обратиться за помощью
- **Описание:** Секция с информацией о каналах поддержки: email поддержка
- **Критерии приёмки:**
  - Отображается email поддержка с иконкой и описанием
  - Все элементы выполнены в стиле glassmorphism

### Часто задаваемые вопросы
- **Цель:** Пользователь находит ответы на типичные вопросы о сервисе
- **Описание:** Блок FAQ с раскрывающимися пунктами: замедление интернета, поддерживаемые устройства (только Android), количество устройств на одной подписке
- **Критерии приёмки:**
  - Отображается список из 3 вопросов
  - При клике на вопрос открывается ответ (аккордеон)
  - Вопросы охватывают: скорость, устройства, мультиподписка

### Карта серверов
- **Цель:** Пользователь видит список доступных стран для подключения
- **Описание:** Секция с карточками стран по регионам: европейские страны (20+), США, Турция. Каждая карточка с флагом и названием страны
- **Критерии приёмки:**
  - Отображаются карточки стран по регионам (Европа, США, Турция)
  - У каждой страны указан флаг и название
  - Стиль glassmorphism

### Блог / SEO-статьи
- **Цель:** Пользователь получает полезную информацию о VPN, DNS и раздельном туннелировании
- **Описание:** Три отдельные страницы блога: /blog/chto-takoe-vpn, /blog/chto-takoe-dns, /blog/razdelnoe-tunnelfrovanie. В футере главной страницы — ссылки на эти статьи
- **Критерии приёмки:**
  - Каждая статья открывается по своему URL
  - Статьи содержат понятное объяснение для обычных пользователей
  - В футере главной страницы отображаются ссылки на все три статьи
  - Стиль статей соответствует общему дизайну (glassmorphism, тёмная тема)

### SEO-оптимизация
- **Цель:** Сайт хорошо индексируется поисковиками и правильно отображается в соцсетях
- **Описание:** Мета-теги и Open Graph на всех страницах, sitemap.xml, robots.txt, структурированные данные Schema.org (Organization, FAQ, Article)
- **Критерии приёмки:**
  - Каждая страница имеет уникальные meta title и description
  - Open Graph-теги (og:title, og:description, og:image) присутствуют на всех страницах
  - Sitemap.xml содержит все страницы сайта
  - Robots.txt разрешает индексацию
  - Структурированные данные Schema.org присутствуют на главной, FAQ и страницах статей

## Дополнительные заметки
- Стиль интерфейса: glassmorphism — стеклянные карточки, размытые фоны, мягкие тени, тёмная тема
- Цветовая схема: бирюзовые тона (teal/cyan) в качестве акцентного цвета
- Аудитория: обычные пользователи (не технические специалисты)
- Все данные статические (прототип), без реальной интеграции с VPN-сервисом
